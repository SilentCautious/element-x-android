## 一句话说明

Element 官方的下一代 [Matrix](https://matrix.org/) 客户端：底层使用 Matrix Rust SDK（Uniffi FFI），UI 使用 Jetpack Compose，导航用 Appyx，采用多 Gradle 模块结构。
